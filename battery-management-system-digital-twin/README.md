# VoltGuard - Advanced Battery Management System Digital Twin

VoltGuard is a self-contained browser app for simulating a 12S lithium-ion pack with cell-level electrical and thermal behavior.

## Features

- Per-cell voltage, SOC, temperature, resistance, balancing, and fault state.
- Pack SOC, SOH, power, equivalent cycle count, and estimator confidence.
- Drive, fast-charge, and storage scenarios with current and ambient-temperature controls.
- Active balancing, voltage-spread monitoring, and thermal/low-SOC protection events.
- Controlled cell-imbalance and thermal-event injection for safety validation.
- Live 90-sample voltage, temperature, and SOC charts plus a timestamped event stream.

## Run

Open `index.html` in a modern browser. No installation, external dependency, or network connection is required.
